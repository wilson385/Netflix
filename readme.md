## 📖 Sobre o Projeto

A **Netflix -** é um projeto desenvolvido com HTML, CSS e JavaScript com o objetivo de simular visualmente a interface da Netflix.

A aplicação possui uma experiência interativa onde o usuário pode inserir seu nome, que será exibido dinamicamente na tela, criando uma sensação personalizada semelhante às plataformas de streaming.

Além disso, o site conta com trailers automáticos de filmes e listas renderizadas de filmes e séries com imagens ilustrativas.

---

## 🚀 Funcionalidades

- Interface inspirada na Netflix
- Trailer automático ao entrar no site
- Troca automática de trailer ao finalizar o vídeo
- Campo para o usuário inserir seu nome
- Exibição dinâmica do nome na interface
- Listas de filmes e séries renderizadas na tela
- Layout moderno e responsivo

---

## 🎥 Recursos da Aplicação

- Reprodução automática de trailers
- Renderização dinâmica de conteúdos
- Manipulação do DOM com JavaScript
- Experiência visual semelhante a plataformas de streaming
